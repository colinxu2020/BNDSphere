# BNDSphere

This project supports only the following databases:

- PostgreSQL: 9.6+ required, 12 or higher recommended

- MySQL: 8.0.13+ required

- SQLite: 3.24.0+ required, 3.25.0 or higher recommended

⚠️ Important Notes:

PostgreSQL is highly recommended for use in production environments.

Please be aware that MariaDB is not supported, despite the support for MySQL.
