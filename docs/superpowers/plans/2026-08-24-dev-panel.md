# Dev Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `RoleEnum.dev`-only panel showing the deployed version against the latest GitHub release, able to trigger a verified update or a one-click rollback, and able to keep reporting progress across the backend restart its own update causes.

**Architecture:** A new `/api/v1/dev` router — separate from `/api/v1/admin`, so system administrators do not get host-level deploy control. The backend reads the updater's status volume (read-only) and writes requests to the request volume (write-only), reporting its own baked-in `APP_VERSION` as ground truth. The React panel polls status and treats connection errors as "still deploying" rather than failure.

**Tech Stack:** FastAPI, pydantic-settings, `httpx` (already bundled with `fastapi[standard]`), pytest, React 19, React Router 7, Tailwind, `motion`.

**Spec:** `docs/superpowers/specs/2026-08-24-deployment-updater-design.md`

## Global Constraints

- Plan 3 of 3. Requires Plan 1 (releases) and Plan 2 (updater sidecar) complete.
- Access is **`RoleEnum.dev` only**. `RoleEnum.admin` must be rejected — this is a deliberate privilege boundary, not an oversight, and it gets its own test (spec §14).
- The backend writes **only** `{id, action, version, requested_at}` (spec §8). Never image names, service names, URLs, or commands.
- The backend mounts `updater_request` **rw** and `updater_status` **ro**. It must never be able to forge updater status (spec §7).
- The running backend's `APP_VERSION` is ground truth for what is serving. `deployed.json` is the updater's record. On divergence the panel shows `APP_VERSION` and disables rollback (spec §7).
- The backend's `409` on an in-flight operation is **advisory**; the updater's lock is authoritative (spec §9).
- UI labels in **Chinese**, matching every other page (`ROLE_MAP` in `frontend/src/lib/labels.ts`).
- No new Python or npm dependencies. `httpx` ships with `fastapi[standard]`.
- **Periodic update check.** The panel must surface a new release without anyone
  clicking anything. Implement it the cheap way: the backend caches the GitHub
  release lookup for 5 minutes, and the panel polls `/status` every 60 seconds
  while it is open (every 3 seconds while an operation is in flight). No cron, no
  scheduler, no background task — a dev-only page that is open is the only time
  anyone needs to know, and the cache keeps the API well inside the
  60-requests-per-hour unauthenticated limit.
- Follow `frontend/src/api/admin.ts` for API wrappers: local types plus `(client.GET as any)` casts. `schema.d.ts` has no generation script; do not add one.
- Commit messages follow Conventional Commits.
- Backend tests: `docker compose -f docker-compose.yml -f docker-compose.dev.yml --profile test run --rm test uv run pytest <args>`

```python
"""Deployment status and update requests.

The backend's role here is deliberately small: it reads what the updater
recorded and writes a version string when a developer asks for one. It cannot
perform an update, and it cannot forge the record of one (spec §4, §7).
"""

import json
import re
import uuid
from dataclasses import dataclass
from datetime import UTC, datetime
from pathlib import Path
from typing import Any, Literal

import httpx

from app.services.errors import BusinessError

# Same grammar the updater enforces (spec §8). Duplicated on purpose: each side
# validates at its own trust boundary, and the updater must never assume the
# backend checked anything.
VERSION_RE = re.compile(r"^v?[0-9]+(\.[0-9]+){0,3}([-+][0-9A-Za-z.-]+)?$")
VERSION_MAX_LEN = 64

TERMINAL_STAGES = frozenset({"idle", "success", "rollback_success", "failed"})


class OperationInFlightError(BusinessError):
    status_code = 409

    def __init__(self, stage: str) -> None:
        super().__init__(
            message_key="error.deployment.operation_in_flight",
            error_code="DEPLOYMENT_OPERATION_IN_FLIGHT",
            details={"stage": stage},
        )


class AlreadyCurrentError(BusinessError):
    status_code = 400

    def __init__(self, version: str) -> None:
        super().__init__(
            message_key="error.deployment.already_current",
            error_code="DEPLOYMENT_ALREADY_CURRENT",
            details={"version": version},
        )


class NoPreviousVersionError(BusinessError):
    status_code = 400

    def __init__(self) -> None:
        super().__init__(
            message_key="error.deployment.no_previous_version",
            error_code="DEPLOYMENT_NO_PREVIOUS_VERSION",
            details={},
        )


@dataclass(frozen=True)
class ReleaseInfo:
    tag: str
    published_at: str | None
    notes: str | None
    url: str


def _version_key(version: str) -> list[int] | None:
    """Numeric segments of a version, or None if it is not comparable."""
    core = version.removeprefix("v").split("-")[0].split("+")[0]
    if not re.fullmatch(r"[0-9]+(\.[0-9]+)*", core):
        return None
    return [int(part) for part in core.split(".")]


def version_newer(candidate: str, current: str) -> bool:
    """True if candidate sorts strictly newer than current.

    Pre-release suffixes are ignored for ordering, matching the shell
    implementation in infra/updater/lib/validate.sh. Full semver precedence
    is not worth the divergence risk between the two.
    """
    candidate_key = _version_key(candidate)
    if candidate_key is None:
        return False
    current_key = _version_key(current)
    if current_key is None:
        # Anything numeric beats a non-numeric current (e.g. the "dev" default).
        return True

    length = max(len(candidate_key), len(current_key))
    padded_candidate = candidate_key + [0] * (length - len(candidate_key))
    padded_current = current_key + [0] * (length - len(current_key))
    return padded_candidate > padded_current


class DeploymentService:
    def __init__(
        self,
        app_version: str,
        github_repo: str,
        github_token: str | None,
        request_dir: Path,
        status_dir: Path,
    ) -> None:
        self.app_version = app_version
        self.github_repo = github_repo
        self.github_token = github_token
        self.request_dir = request_dir
        self.status_dir = status_dir

    # ── reads ────────────────────────────────────────────────────────

    def _read_json(self, name: str, default: dict[str, Any]) -> dict[str, Any]:
        path = self.status_dir / name
        try:
            return json.loads(path.read_text())  # type: ignore[no-any-return]
        except FileNotFoundError:
            return default
        except (json.JSONDecodeError, OSError):
            # The updater writes atomically, so this should be unreachable.
            # If it happens, the panel must still load and say something true.
            return {"stage": "unknown"}

    def updater_state(self) -> dict[str, Any]:
        return self._read_json("state.json", {"stage": "idle"})

    def deployed(self) -> dict[str, Any]:
        return self._read_json("deployed.json", {})

    def log_tail(self, limit: int = 200) -> list[str]:
        try:
            lines = (self.status_dir / "update.log").read_text().splitlines()
        except (FileNotFoundError, OSError):
            return []
        return lines[-limit:]

    def current_version(self) -> str:
        """What is actually serving.

        Not deployed.json: an updater crash can leave that record ahead of
        reality, and a panel that trusts the record over the process will
        confidently report a version that is not running (spec §7).
        """
        return self.app_version

    def previous_version(self) -> str | None:
        return self.deployed().get("previous_version") or None

    def is_busy(self) -> bool:
        return self.updater_state().get("stage", "idle") not in TERMINAL_STAGES

    def record_diverged(self) -> bool:
        """True when deployed.json disagrees with what is running."""
        recorded = self.deployed().get("current_version")
        return bool(recorded) and recorded != self.app_version

    # ── GitHub ───────────────────────────────────────────────────────

    async def latest_release(self) -> ReleaseInfo | None:
        headers = {"Accept": "application/vnd.github+json"}
        if self.github_token:
            headers["Authorization"] = f"Bearer {self.github_token}"

        url = f"https://api.github.com/repos/{self.github_repo}/releases/latest"
        try:
            async with httpx.AsyncClient(timeout=10.0) as http:
                response = await http.get(url, headers=headers)
        except httpx.HTTPError:
            return None

        if response.status_code != 200:
            # 404 = no releases yet, 403 = rate limited. Both are states the
            # panel should render, not errors that break it.
            return None

        payload = response.json()
        return ReleaseInfo(
            tag=payload["tag_name"],
            published_at=payload.get("published_at"),
            notes=payload.get("body"),
            url=payload["html_url"],
        )

    # ── writes ───────────────────────────────────────────────────────

    def write_request(
        self,
        action: Literal["update", "rollback"],
        version: str,
    ) -> str:
        if action not in ("update", "rollback"):
            msg = f"invalid action: {action!r}"
            raise ValueError(msg)
        if len(version) > VERSION_MAX_LEN or not VERSION_RE.fullmatch(version):
            msg = f"invalid version: {version!r}"
            raise ValueError(msg)

        request_id = str(uuid.uuid4())
        payload = {
            "id": request_id,
            "action": action,
            "version": version,
            "requested_at": datetime.now(UTC).strftime("%Y-%m-%dT%H:%M:%SZ"),
        }

        # Write-temp-then-rename so the updater, which polls this path, never
        # reads a partial request.
        self.request_dir.mkdir(parents=True, exist_ok=True)
        tmp = self.request_dir / "request.json.tmp"
        tmp.write_text(json.dumps(payload))
        tmp.replace(self.request_dir / "request.json")

        return request_id
```

```python
from typing import Annotated, Any

from pydantic import BaseModel, Field, StringConstraints

# Mirrors the updater's grammar (spec §8). Rejecting at the schema layer turns
# a malformed version into a 422 before it can reach the request file.
VersionStr = Annotated[
    str,
    StringConstraints(
        pattern=r"^v?[0-9]+(\.[0-9]+){0,3}([-+][0-9A-Za-z.-]+)?$",
        max_length=64,
    ),
]


class ReleaseSummary(BaseModel):
    tag: str
    published_at: str | None
    notes: str | None
    url: str


class DeploymentStatus(BaseModel):
    current_version: str
    previous_version: str | None
    latest_release: ReleaseSummary | None
    update_available: bool
    # True when deployed.json disagrees with the running APP_VERSION; rollback
    # is disabled in that state (spec §7).
    record_diverged: bool
    stage: str
    action: str | None
    trigger: str | None
    target_version: str | None
    delivery_path: str | None
    error_code: str | None
```

```python
from fastapi import APIRouter

from app.api.dependencies import DeploymentServiceDep
from app.schemas.deployment import (
    DeploymentStatus,
    ReleaseSummary,
    RequestAccepted,
    UpdateRequest,
)
from app.services.deployment import (
    AlreadyCurrentError,
    NoPreviousVersionError,
    OperationInFlightError,
    version_newer,
)

router = APIRouter()


async def _build_status(service: DeploymentServiceDep) -> DeploymentStatus:
    state = service.updater_state()
    current = service.current_version()
    release = await service.latest_release()

    return DeploymentStatus(
        current_version=current,
        previous_version=service.previous_version(),
        latest_release=(
            ReleaseSummary(
                tag=release.tag,
                published_at=release.published_at,
                notes=release.notes,
                url=release.url,
            )
            if release
            else None
        ),
        update_available=bool(release and version_newer(release.tag, current)),
        record_diverged=service.record_diverged(),
        stage=state.get("stage", "idle"),
        action=state.get("action") or None,
        trigger=state.get("trigger") or None,
        target_version=state.get("target_version") or None,
        delivery_path=state.get("delivery_path") or None,
        error_code=state.get("error_code") or None,
        error_message=state.get("error_message") or None,
        started_at=state.get("started_at") or None,
        finished_at=state.get("finished_at") or None,
        log_tail=service.log_tail(),
        updater_state=state,
    )


@router.get("/status", response_model=DeploymentStatus)
async def get_status(service: DeploymentServiceDep) -> DeploymentStatus:
    return await _build_status(service)


@router.post("/check", response_model=DeploymentStatus)
async def check_for_update(service: DeploymentServiceDep) -> DeploymentStatus:
    # The GitHub read is not cached in v1; this endpoint exists so the panel
    # has an explicit "refresh" affordance rather than relying on polling.
    return await _build_status(service)


@router.post("/update", response_model=RequestAccepted, status_code=202)
async def request_update(
    body: UpdateRequest,
    service: DeploymentServiceDep,
) -> RequestAccepted:
    # Advisory only: the updater's lock is authoritative and will reject a
    # racing second request on its own (spec §9).
    if service.is_busy():
        raise OperationInFlightError(service.updater_state().get("stage", "unknown"))
    if body.version == service.current_version():
        raise AlreadyCurrentError(body.version)

    request_id = service.write_request("update", body.version)
    return RequestAccepted(request_id=request_id, action="update", version=body.version)


@router.post("/rollback", response_model=RequestAccepted, status_code=202)
async def request_rollback(service: DeploymentServiceDep) -> RequestAccepted:
    if service.is_busy():
        raise OperationInFlightError(service.updater_state().get("stage", "unknown"))

    previous = service.previous_version()
    if not previous:
        raise NoPreviousVersionError

    # The version is taken from the updater's own record, never from the
    # client. A rollback target the caller could choose would be an image
    # selector by another name (spec §8).
    request_id = service.write_request("rollback", previous)
    return RequestAccepted(request_id=request_id, action="rollback", version=previous)
```
